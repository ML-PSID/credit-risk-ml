# Product

## Register

product

## Users

Students, instructors, and jury members evaluating a data analytics and machine learning project. They use the application during review or demonstration to understand the dataset, inspect credit-risk signals, and compare model behavior.

## Product Purpose

The product turns the UCI credit card default dataset into an explorable web dashboard. It explains the risk story through portfolio indicators, payment-delay analysis, financial tension signals, and machine learning model evaluation. Success means a viewer can quickly understand which variables matter, how the Random Forest behaves, and how a Logistic Regression baseline compares against it.

## Brand Personality

Analytical, clear, and serious. The interface should feel like a focused data product rather than a marketing page: structured, readable, and confident enough for an academic jury.

## Anti-references

Avoid landing-page composition, decorative visuals without analytical value, oversized promotional hero sections, and isolated charts without interpretation. Avoid making the Logistic Regression feel like an appendix; it should be comparable to the Random Forest.

## Design Principles

- Prioritize comparison: equivalent model sections should use equivalent visual structure.
- Explain through evidence: charts, metrics, and short interpretation notes must work together.
- Keep the workflow scannable: users should move from summary to detailed diagnostics without hunting.
- Respect the academic context: visual polish should support clarity, not distract from results.
- Preserve analytical continuity: dashboard insights, Random Forest results, and Logistic Regression results should feel like one coherent story.

## Accessibility & Inclusion

The interface should remain readable on desktop and mobile, with sufficient text contrast, responsive chart containers, and reduced-motion support for decorative animations. The project should avoid relying on color alone to communicate model status or class meaning.
